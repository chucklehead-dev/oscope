# Stock-runtime reader layering screen

This reuses existing data.json work rather than introducing another parser.
Source: casselc/data.json `83b0e97d88a322e870c297c8e14261b727572d73`,
an ancestor-compatible descendant of the app's selected `0f51b991` (verified
with `git merge-base --is-ancestor`). No application dependency pin changed.

On official Jolt 0.8.23 / mandatory Chez 10.4.1, the existing public
`clojure.data.json.jolt-native/load-string-reader!` loads without a compiler
fork. Binding `json/*experimental-native-string-reader*` explicitly enables it.
The similarly named writer has a separate custom-runtime helper requirement;
do not confuse writer requirements with the reader's.

## Matched observations

Twelve measured samples per mode, two warmup rounds, alternating forward and
reverse mode order in one process. Parsing is timed; fixture construction and
complete result equality checks are outside timing. Raw samples and all four
requested percentiles are adjacent. With twelve samples, p95/p99 are maxima,
not population-tail qualification. No allocation claim follows from this run.

| Fixture | Portable p50 | Native token p50 | Reader-backed p50 |
| --- | ---: | ---: | ---: |
| 256 plain strings | 2.43 ms | 0.76 ms | 5.62 ms |
| 1,024 plain strings | 33.86 ms | 4.24 ms | 18.62 ms |
| 2,048 plain strings | 127.94 ms | 5.71 ms | 40.54 ms |
| 2,048 escaped strings | 29.71 ms | 6.14 ms | 66.42 ms |
| Actual 512-span wire fixture (653,705 characters) | 328.99 ms | 244.33 ms | 896.68 ms |

The actual fixture is generated by this branch's unchanged `payload` function,
with a fixed timestamp and its ordinary JSON writer. All parsed results match.
The native token hook reduces its median parse time by about 26%, not the
22x seen on the adversarial unescaped-array case. The remaining document
parser/materialization must be measured rather than inferred from string-only
tests. It already uses transient maps/vectors; replacing persistent insertion
with transients is not a new opportunity here.

This is pure parsing, not HTTP, SDK export, WAL publication or recovery.
No confirmed-throughput improvement, whole-app packaging support, fault
invariant proof or S3 result is claimed. Controls cover null, booleans, numbers,
empty/plain strings, simple/Unicode/surrogate-pair escapes and three malformed
inputs; they do not replace the library's full conformance tests.

## Reproduce

Use the pinned wrapper and stock binary recorded in `run-pair.sh`.
From this checkout:

```sh
/home/chuck/ai-src/tools/jolt-with-chez-10.4.1 \
  /home/chuck/.cache/jolt-stock-v0.8.23-codec/jolt-v0.8.23-x86_64-linux/jolt \
  -Srepro -Sdeps '{:paths ["src" "benchmark"] :deps {org.clojure/data.json {:git/url "https://github.com/casselc/data.json.git" :git/sha "83b0e97d88a322e870c297c8e14261b727572d73"}}}' \
  research/socket-ingest-20261020/reader-layer-screen.clj socket-fixture
```

Omit `socket-fixture` to run the bounded string-array screen. The loader is
explicit, scoped, default-off and installs no global parser. Standalone/AOT
reader qualification remains separate; the loader itself says unqualified.
